# 🌤️ SkyCast 天空播报

一个纯前端的天气预报小网页：输入城市名，查看未来 7 天天气；点击某一天，整页背景动画会随当天天气切换（晴 / 雨 / 雪 / 雷 / 多云 / 雾）。

## 功能

- 🔍 搜索任意城市（支持中文名）
- 📅 未来 7 天预报，每天一张卡片
- 🎬 点击某天，背景动画随天气切换
- 📍 一键定位我的位置
- 🌡️ 显示最高/最低温、降水概率、风速、日出日落、紫外线

## 怎么用

直接用浏览器打开 `index.html` 即可，无需安装任何东西。

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，无框架、无第三方库
- 天气数据来自免费的 [Open-Meteo API](https://open-meteo.com/)（无需密钥）
- 所有天气动画均用纯 CSS 实现

## 文件结构

| 文件 | 作用 |
|------|------|
| `index.html` | 页面骨架 |
| `style.css` | 所有样式和天气动画 |
| `app.js` | 全部逻辑（取数据、画卡片、切换动画） |
